Advanced Recovery Code Standard

With the massive amounts of data routinely used and stored in the modern day, corruption is routine and expected.

ARCS is a standard specifying a scheme for packaging any piece of data with a recovery code capable that helps in error detection and allows the original bits to be recreated in case of corruption. Many digital files created in the modern incorporate an ARCS field, and undergo routine integrity checks and repair.

It incorporates a number of algorithms, most notably Reed-Solomon error correction codes.
