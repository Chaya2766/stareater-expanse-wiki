Respawn machine

A machine which will reconstruct the user in a new body after their death is commonly known as a "respawn machine" inspired by gaming vocabulary where respawning is the term for the player coming back into the game after death.

Respawn machines are typically only known by that name for either organic users or digitals who insist on existing as only one active copy at a time. Respawn machines for digitals can be very simple, so most of the discourse on this topic concerns organics - this page as so will focus mainly on respawn machines for organics.

Typical function

A respawn machine usually takes care of 2 or 3 tasks that can be singled out and described separately:
  1. Safely storing a backup of the user's mind
  2. When needed, recreating the user's brain and implanting it into a new body
  3. Growing or storing backup bodies for the user to be implanted into
Each of these is a nontrivial task.

Mind storage

The respawn machine must safely store data needed to recreate the user. This means keeping it safe from data corruption, safe from external tampering by unauthorized parties, and safe from being copied out of the machine by an unauthorized party.

A fairly common security feature is multi-key asymetric encryption, with which the data stored in the machine is completely useless and unreadable until a sufficient number of authorized parties provide partial decryption keys to it. For example in a 2-of-3 arrangement, the user and two other trusted parties hold decryption keys. Since the encryption is asymetric, it can be configured such that the user can update the data in their machine without needing anyone else's help, but decrypting the data requires at least two of the partial keys. This way an attacker would have to not only compromise the machine but also compromise two other people's security to gain an unauthorized copy of the user. 2-of-2, 2-of-3 and 3-of-5 are all fairly common choices for this method.

1-of-1 encryption is a particularly good option if multiple instances of the user exist at the same time - if any instance of the user has a fatal incident, one of the remaining living instances would use their key to allow a respawn. This fails if all instances of the user die at the same time, as in that case there is no remaining person alive who can provide the key.

Those concerned enough may also include a tamper failsafe which wipes all the data from the machine if it detects a physical intrusion or loses power, some however do prefer the risk of their mind being stolen to the risk of their death becoming permanent if someone tampers with their respawn machine. Data such as this is generally too important to store in one place, so the risk of permanent death occurs only if the user neglected to hold copies elsewhere and was also dead at the time that their respawn machine wiped itself.

Digital respawn machines

Respawn machines for digitals can be very simple, and as such are often not standardized.

One common setup consists of a ready body pre-loaded with a copy of the digital which simply had not been activated yet. In that setup, the body counts down a timer which will activate the dormant copy once it runs out, and listens for a singnal that the original is still alive. The timer is reset every time a valid signal is received, and as such will activate once the original is dead, unless they died to an adversary both sophisticated enough and dedicated enough to hijact their routine and keep sending out the signal until they find the dormant body.
