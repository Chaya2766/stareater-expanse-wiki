Data storage

Data storage technologies in common use throughout the Stareater Expanse.

5D optical data storage

Data can be written into innert transparent materials like fused quartz using femtosecond laser pulses, which induce a local defect that affects intensity and polarization of any light passing through it. In this way data is encoded in 5 dimensions: the three spatial dimensions of the defect's position as well as intensity and polarization offset. This allows data densities where each bit could take up a volume only 2nm across, but in practice this method does not store each bit individually so the size of each defect encoding the bits is going to be much larger than that.

A compact disc made of fused quartz such as that shown on the right (12cm in diameter) is able to store 2.88e15 bits of data for billions of years without degradation. This is a convenient format but notably much of it's thickness serves purely structural purpose, limited to an aerial data density of 2.5869e13 bits/cm2 regardless of thickness.

The thicker block shown next to it would store only 16TB of data, with even more robustness added by the extra material.

Tape drives utilizing similar technology could make much fuller use of the achievable data density up to a theoretical maximum of 1.25e20bits/cm3 if one were to use thinnest possible ribbon of fused quartz with absolutely no support structure, or somewhere in the order of magnitude below that with more reasonable practical designs, fairly easily reaching whole exabytes of capacity in a pocketable format.

In an example of a top tier device using this technology, a pocketable drive sized 2cm by 6cm by 12cm can store 5.3EB of data and achieve write speeds of nearly 1PB/s with 100-nanometre thin fused quartz tape. A less advanced device using 1-micrometre thick tape can store 24 Exabytes of data and write at 308TB/s while still remaining somewhat portable, in a form factor of 12cm by 12cm by 24cm. spintronic memory

It is possible to create spintronic logical circuits, which instead of using charge of particles, use their spin. As they also tend to not be volatile, this also enables data storage devices to be made with them.

Spintronic NAND gates are commonly made around a little over 427nm3 in size, much smaller than their electronic counterparts. Simply filling a volume with NAND gates would yield about 2.339e18 bits/cm3 data density, which is a good approximation for an absolute upper limit but there's a lot more supporting circuitry that needs to fit into that same volume to produce a working data storage device. In practice this technology stays an order of magnitude below that theoretical limit, roughly 2.4e17 bits/cm3 a notable case being the Civic-5 chip that showcases both the great data density and the logic circuit capability of this technology in one device.

Spintronic memory is a step below optical data storage in terms of data density, but enables rapid reading, writing and re-writing.
